## 목적

- 이 주제를 확인하는 이유: About URL 공유 시 깨지지 않는 대표 이미지 정책을 정한다.
- 이 주제가 불명확하면 생기는 리스크: 존재하지 않는 이미지를 소셜 크롤러에 제공해 미리보기가 비거나 실패한다.

## 코드·운영 근거로 자답한 내용

- About metadata는 1200×630 `/og/about.png`를 명시한다.
- 해당 파일은 현재 저장소에 없고 운영 URL도 404다.
- About의 제목과 설명은 별도로 정의돼 있어 이미지 정책만 결정하면 된다.
- 최소 변경은 존재하지 않는 이미지 선언을 제거하고 공통 이미지를 상속하는 것이다. 전용 이미지는 About의 작성자 소개 성격을 더 잘 표현한다.

## Interview Log

1. **질문:** About 페이지는 전용 작성자 소개 이미지를 사용할 것인가, 사이트 공통 이미지를 사용할 것인가?
   - **답변:** About 전용 이미지를 제작한다. 2D 애니메이션 스타일의 귀여운 남자 개발자 일러스트를 사용한다.

## Score

## Confirmed

- 현재 `/og/about.png`의 404 상태를 해소하고 해당 경로에 1200×630 전용 공유 이미지를 추가해 metadata 선언을 유지한다.
- 이미지는 2D 애니메이션 스타일의 귀여운 남자 개발자 일러스트로 제작한다.
- 실제 인물의 얼굴을 재현한다는 결정은 포함하지 않는다.

## Open Questions
