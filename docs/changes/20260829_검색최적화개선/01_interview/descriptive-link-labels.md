## 목적

- 이 주제를 확인하는 이유: 링크의 목적을 검색 엔진과 보조 기술, 독자가 문맥 없이도 이해하게 한다.
- 이 주제가 불명확하면 생기는 리스크: 서로 다른 목적지가 동일한 `읽기`로 노출되고 `전체 보기`의 대상도 모호해 Lighthouse SEO·접근성 점수가 낮아진다.

## 코드·운영 근거로 자답한 내용

- 추천 글과 최근 글의 보조 링크는 서로 다른 게시물로 이동하지만 모두 `읽기`로 표시된다.
- 섹션 헤더의 `/posts` 링크는 `전체 보기`로 표시된다.
- 카드에는 이미 제목 링크와 전체 카드 접근성 링크가 있어 보조 링크 문구를 바꿀 때 중복 읽기 경험을 함께 검토해야 한다.
- Lighthouse SEO 92의 직접 원인 중 하나는 설명이 부족한 `/posts` 링크다.
