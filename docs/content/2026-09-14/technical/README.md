`*.original.mdx`는 2026-09-14 운영 DB의 읽기 전용 조회에서 얻은 본문을 줄바꿈까지 그대로 보존했습니다. `manifest.json`의 SHA-256과 바이트 일치 검증으로 확인했습니다. 원본 제목·slug·생성일·발행일·커버·태그는 갱신 대상이 아닙니다. 전체 원본/보존 필드 백업은 워크트리 외부 `/Users/mion/.codex/tmp/adsense-fix-20260914/originals/{slug}.json`에 0600 권한으로 보관합니다. 공개 화면 원문도 `technical-live/`에 HTTP 200 응답으로 별도 확보했습니다.

세 글 원문에 본문 이미지 URL은 없습니다. JWT의 기존 도표 3개는 잘못된 인증·용어 관계를 포함하고 있어 도표 3개로 교정했고, 파트 구조와 라이브러리·비교 정보를 유지했습니다. 서명 유효성을 알 수 없는 고정 토큰 및 생략된 JWE 문자열은 실제 실행 가능한 생성·검증 예제로 대체했습니다. 사고 글의 두 마스킹된 로그 블록과 URL·시각은 보존했습니다. AWS 글은 소개와 10개 비교 주제를 유지했습니다. 원래 공식 참고 링크는 세 글 모두 없었으며 새 공식 링크를 문장에 연결했습니다.

## 원본 대비 변경

### JWT와 JWE

- JWT를 서명 방식으로 한정한 설명을 JWS 또는 JWE로 표현되는 클레임 형식으로 교정했습니다.
- 변조 불가능을 변조 검출로, 복호화 성공을 클레임 검증·권한 판단과 분리했습니다. MAC과 비대칭 서명, 공개 헤더, 중첩 JWT, 암호화만으로 발급자를 인증할 수 없는 조건을 설명했습니다.
- 서명된 JWT/JWE의 구조, 보안 특성, 라이브러리 비교를 유지하면서 길이·성능의 무조건적인 우열을 제거했습니다.
- `jwtExample.mjs`를 본문에 그대로 포함했습니다. 이번 수정에서 생성한 예제 전용 키/클레임으로 검증했으며 과거 실무 경험으로 표현하지 않았습니다.
- 근거: RFC 7519 §3, RFC 7515/7516, RFC 8725, jose와 Auth.js 공식 문서. 링크는 개정 본문에 있습니다.

### Next.js 사고 기록

- 힙 오버플로우·메모리 커럽션 설명을 React의 요청 디코딩·역직렬화 결함 설명으로 교정했습니다.
- 503 확인일과 UTC 로그 시각, 환경변수 문자열 기록과 외부 유출 확정, 다운로드와 실행 성공을 구분했습니다.
- 공개된 마스킹 로그와 당시의 패치/Distroless 결정 기록을 유지하면서 전체 로그·이미지·배포 증빙이 없다는 범위를 밝혔습니다.
- 2025년 최초 수정 버전을 현재 권장 버전처럼 안내하지 않으며 후속 공식 보안 공지·지원 계열 확인과 패치 이후 비밀 교체 절차를 설명했습니다.
- 근거: React CVE-2025-55182 공지, Next.js CVE-2025-66478 및 후속 보안 공지, Next.js 환경변수와 Distroless 공식 문서.

### AWS와 Railway

- 비공개 S3 호환 Railway Buckets, 서명 URL/중계, 리전·호환 범위·파일 제공 비용 조건을 추가했습니다.
- AWS 공식 저장소만 사용 가능, EC2까지 완전 관리형, 자동 수평 확장, 커뮤니티 지원만 가능 등의 과도한 일반화를 교정했습니다.
- DB·볼륨 백업, 고가용성 템플릿, 수직 확장과 수평 복제본, 플랜별 지원, 비용 산정 입력을 재검토했습니다.
- App Runner 신규 고객 이용 종료와 기존 고객 계속 이용 조건을 공식 문서로 확인해 명시했습니다.
- 플랫폼/조건 비교이며 실제 신규 비용·성능 수치를 측정하지 않았음을 밝혔습니다. 제품 확인 기준일을 명시하고 발행일은 보존합니다.

## 검증

- Node.js 24.9.0 / jose 6.2.12: 정상 JWS 검증·본문 디코딩, 변조·다른 수신 대상·만료 거부, 정상 JWE 복호화·암호문 변조 거부 모두 통과했습니다.
- MDX 3 + remark-gfm 4 + 저장소 `remark-mermaid.js`: 세 개정 MDX 컴파일 통과했습니다.
- Mermaid 11.12.0 공식 파서: 도표 3개 통과했습니다. 스킬 정적 검사도 오류·경고 0입니다. 브라우저에서 SVG 렌더링한 검증은 아닙니다.
- 원본 MDX 바이트 일치 및 SHA-256, 원래 로그 URL 보존을 확인했습니다.
- 생성 도구는 실 운영 백업과 개정 MDX로 실행했습니다. 조건부 UPDATE의 읽기 전용 `EXPLAIN`은 각 글 원본 조건 일치 1건을 확인했고 UPDATE를 실행하지 않았습니다.
- 런타임 앱 변경이 없어 전체 앱 테스트는 실행하지 않았습니다. 운영 갱신·캐시·본문·브라우저 확인은 미실행입니다.

## 운영 적용

[공유 도구와 절차](../tools/README.md)를 따릅니다. API의 content 단독 요청은 기존 커버와 요약을 없앨 위험이 있어 사용하면 안 됩니다. 이번 본문 전용 변경에는 모든 안정 필드와 태그를 원본과 대조하는 조건부 SQL을 우선 검토합니다. 생성된 검토 SQL은 기본 ROLLBACK이며 후속 승인 전에는 실행하지 않습니다. 실제 적용 후 DB 보존값 검증과 공개 화면·캐시 확인을 모두 통과해야 완료입니다.
